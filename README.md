# TradeScope

Учебное веб-приложение на Go для бэктестинга трёх торговых стратегий на дневных
котировках из CSV. Все стратегии используют один набор данных, одинаковый
капитал, комиссию и проскальзывание, поэтому результаты можно сравнивать.

## Возможности

- загрузка CSV с котировками (Date, Open, High, Low, Close, Volume);
- три стратегии с настраиваемыми параметрами: SMA Crossover, RSI Mean Reversion,
  MACD;
- единый long-only бэктест: одна позиция, полное вложение капитала, комиссия и
  проскальзывание, исполнение сигнала по цене открытия следующей свечи;
- метрики: доходность, максимальная просадка, число сделок, Win Rate, средняя
  доходность сделки, коэффициент Шарпа;
- пять графиков на Canvas, таблица сравнения и автоматические выводы.

## Структура

```
cmd/server/          HTTP-сервер и маршрут /api/backtest
cmd/experiment/      воспроизведение эксперимента для отчёта
internal/tradescope/ CSV, стратегии, бэктест, метрики
web/                 HTML, CSS и JavaScript
data/samples/        демонстрационные данные AAPL
report/              пояснительная записка на Typst
```

## Запуск

```bash
go run ./cmd/server
```

Откройте <http://localhost:8080>. Демонстрационный набор AAPL загружается
автоматически; собственный CSV можно выбрать в правом верхнем углу.

Флаги сервера:

```bash
go run ./cmd/server -addr :8080 -data data/samples/aapl_daily.csv -web web
```

## Эксперимент

```bash
go run ./cmd/experiment
```

Команда пересчитывает результаты и обновляет `report/generated/results.typ` и
`report/generated/results.json`.

Фактические результаты на AAPL, 1510 дневных свечей (02.01.2019–31.12.2024),
капитал 10 000 у.е., комиссия 0,10 %, проскальзывание 0,05 %:

| Стратегия | Доходность | Просадка | Сделок | Sharpe |
|---|---:|---:|---:|---:|
| SMA Crossover | +193,34 % | 28,21 % | 16 | 0,95 |
| RSI Mean Reversion | +65,33 % | 26,22 % | 6 | 0,53 |
| MACD | +228,02 % | 18,91 % | 54 | 1,17 |
| Покупай и держи | +534,30 % | 31,43 % | — | — |

## Пояснительная записка


Готовый PDF: `report/coursework.pdf`, 27 страниц. Исходный шаблон сохранён в
`docs/Typst_report_template/`.

## Ограничения

Результаты получены на одном инструменте и одном периоде с сильным восходящим
трендом. Параметры не оптимизировались, дивиденды не учитываются, комиссия и
проскальзывание постоянны. Это учебный проект, а не инвестиционная рекомендация.
