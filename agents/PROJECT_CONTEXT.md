# TradeScope — Project Context

## Project topic
Исследование алгоритмических торговых стратегий на основе анализа временных рядов и их визуализация.

## Project goal
Снизить временные затраты на оценку эффективности алгоритмических торговых стратегий на основе исторических данных, используя числовые показатели и графическую визуализацию результатов.

## Technologies
- Go 1.27
- HTML
- CSS
- JavaScript
- Typst
- CSV

## Main functionality
1. Загрузка исторических котировок из CSV.
2. Применение трёх алгоритмических торговых стратегий.
3. Историческое моделирование торговли (backtesting).
4. Расчёт показателей эффективности.
5. Сравнение стратегий.
6. Визуализация результатов на веб-сайте.

## Strategies
- SMA Crossover
- RSI Mean Reversion
- MACD

## Main metrics
- Итоговая доходность.
- Максимальная просадка.
- Количество сделок.
- Win Rate.
- Коэффициент Шарпа.

## Architecture
Небольшое монолитное Go-приложение.
Предпочтительно использовать стандартную библиотеку Go.
Не применять избыточную архитектуру.

## Documentation
Пояснительная записка оформляется в Typst.
В проекте уже может находиться подготовленный Typst-шаблон.
Его необходимо сохранить и использовать.

## Important
Все результаты экспериментов должны быть получены фактическим запуском программы.
Запрещено выдумывать статистику, источники данных и результаты.
